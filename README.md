# Runflat

A responsive, offline-friendly route planning demo for finding lower-climb runs in San Francisco.

## Run locally

```bash
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173).

The demo uses a hand-curated local route dataset and a stylized SVG map. It does not provide live street closures, GPS directions, or safety conditions.
